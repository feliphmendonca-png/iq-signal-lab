1. Carregar candles históricos (CSV)

Escolha um arquivo CSV com candles de 1 minuto. A ferramenta tenta reconhecer colunas de data/hora, open, high, low e close. O arquivo é processado localmente no navegador.

Formato esperado

Uma linha por candle, com cabeçalho. Exemplo:

timestamp,open,high,low,close
2026-01-01 10:00:00,1.1000,1.1010,1.0995,1.1005

Valores ilustrativos, não cotações reais. Separe colunas por vírgula ou ponto e vírgula. Use pelo menos 100 candles para um teste inicial.

4. Próximos cuidados

  • Teste vários períodos e ativos, sem escolher apenas os melhores resultados.
  • Reserve dados mais recentes para validação; não ajuste a regra usando todo o histórico.
  • Use dados do mesmo provedor/preço da plataforma quando possível. OTC exige validação específica.
  • Uma taxa direcional acima de 50% não garante lucro. Pagamento, expiração, atraso e custos mudam o resultado.
  • Não envie senhas da corretora ou chaves de API para este arquivo.
